# EGH455-Group-12
Repository for sharing and keeping files for our drone payload project.

## Subsystems

Each subsystem has its own Python entry point and README:

| Subsystem | Entry point | Documentation |
| --- | --- | --- |
| AIP | `aip/aip_main.py` | [AIP README](aip/README.md) |
| AQ | `aq/aq_main.py` | [AQ README](aq/README.md) |
| DE | `de/de_main.py` | [DE README](de/README.md) |
| WVI | `wvi/wvi_main.py` | [WVI README](wvi/README.md) |

The entry points are scaffolds for future subsystem integration. Existing
hardware scripts are documented in the corresponding subsystem README.

## DepthAI Setup
